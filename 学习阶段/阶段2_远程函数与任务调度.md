## 1. 远程函数核心流程回顾

```
定义            提交             获取结果
@ray.remote  →  .remote(args)  →  ray.get(future)
  函数            ObjectRef         实际返回值
```

三个关键对象：

| 对象 | 含义 | 类比 |
|------|------|------|
| `@ray.remote` | 把函数变成远程任务 | 把菜名告诉厨房 |
| `.remote(args)` | 提交任务，返回 ObjectRef | 拿到取餐小票 |
| `ObjectRef` | 任务的引用（future） | 取餐小票本身 |
| `ray.get(ref)` | 阻塞等待，取回结果 | 拿小票去取餐 |

## 2. ray.get() vs ray.wait()

这是阶段二最重要的知识点。

### ray.get() — 全部拿到才返回

```python
import ray, time
ray.init(address='auto')

@ray.remote
def slow_task(seconds):
    time.sleep(seconds)
    return f"睡了 {seconds}s"

futures = [slow_task.remote(1), slow_task.remote(3), slow_task.remote(5)]

# ray.get 会等到所有任务完成，总共等 5 秒（并行执行）
results = ray.get(futures)
# [f"睡了 1s", f"睡了 3s", f"睡了 5s"]

ray.shutdown()
```

**问题：** 如果有一个任务要跑 1 小时，其他 1 秒就完成了，你也得等 1 小时才能看到任何结果。

### ray.wait() — 谁先完成先处理谁

```python
import ray, time
ray.init(address='auto')

@ray.remote
def slow_task(seconds):
    time.sleep(seconds)
    return f"睡了 {seconds}s"

futures = [slow_task.remote(5), slow_task.remote(1), slow_task.remote(3)]

remaining = futures
while remaining:
    # 等待至少 1 个任务完成
    done, remaining = ray.wait(remaining, num_returns=1)
    result = ray.get(done[0])
    print(f"完成: {result}")

# 输出顺序（按完成时间，不是提交顺序）：
# 完成: 睡了 1s
# 完成: 睡了 3s
# 完成: 睡了 5s

ray.shutdown()
```

### 对比总结

| | `ray.get()` | `ray.wait()` |
|---|---|---|
| 阻塞方式 | 等所有任务完成 | 等指定数量的任务完成 |
| 返回值 | 结果列表 | (已完成列表, 未完成列表) |
| 适用场景 | 必须全部完成才能继续 | 流式处理，谁先完成先处理谁 |
| 超时控制 | `ray.get(futures, timeout=5)` | `ray.wait(futures, timeout=5)` |

### ray.wait() 参数详解

```python
done, remaining = ray.wait(
    object_refs,       # ObjectRef 列表
    num_returns=1,     # 至少等几个完成就返回
    timeout=None       # 最长等多久（秒），None 表示无限等
)
# done: 已完成的 ObjectRef 列表
# remaining: 未完成的 ObjectRef 列表
```

## 3. 资源控制：num_cpus

### 默认行为

不指定 `num_cpus` 时，每个任务默认占用 **1 个 CPU**。集群有 20 核，所以最多 20 个任务同时运行。

### 指定资源

```python
@ray.remote(num_cpus=4)
def heavy_task():
    ...

# 集群 20 核，每个任务占 4 核 → 最多 5 个并行
```

### 资源不足时自动排队

```python
@ray.remote(num_cpus=15)
def big_task(i):
    time.sleep(3)
    return i

# 提交 3 个任务
futures = [big_task.remote(i) for i in range(3)]

# 集群 20 核，每个任务 15 核：
# 第 1 个：立即开始（15 核被占用，剩余 5 核）
# 第 2 个：等第 1 个完成（5 核不够 15 核）
# 第 3 个：等第 2 个完成
# 总耗时约 9 秒（3 轮 × 3 秒）
```

### 关键理解

```
任务提交后不是"立即执行"，而是"进入调度队列"

调度器检查：
  任务需要 num_cpus=N
  当前是否有节点有 >= N 个空闲 CPU？
    有 → 分配到该节点执行
    没有 → 排队等待，直到有资源释放
```

## 4. ray.put()：手动放入共享内存

### 为什么需要 ray.put

当多个任务需要同一份数据时，`ray.put()` 把数据放入共享内存一次，后续任务直接引用，避免重复传输。

```python
import ray, time
ray.init(address='auto')

big_list = list(range(10_000_000))

# ❌ 方式 1：每次都传 big_list 的副本
@ray.remote
def process_v1(data, i):
    return sum(data) + i

start = time.time()
futures = [process_v1.remote(big_list, i) for i in range(10)]
ray.get(futures)
print(f"每次传副本: {time.time()-start:.2f}s")


# ✅ 方式 2：先 put 一次，所有任务共享同一份数据
data_ref = ray.put(big_list)

@ray.remote
def process_v2(data_ref, i):
    data = ray.get(data_ref)
    return sum(data) + i

start = time.time()
futures = [process_v2.remote(data_ref, i) for i in range(10)]
ray.get(futures)
print(f"先 put 再共享: {time.time()-start:.2f}s")

ray.shutdown()
```

### 什么时候用 ray.put

| 场景 | 是否需要 ray.put |
|------|------------------|
| 多个任务需要同一份大数据 | ✅ 需要，避免重复传输 |
| 每个任务用不同的数据 | ❌ 不需要，直接传参 |
| 数据很小（几个数字） | ❌ 不需要，开销可忽略 |

## 5. 任务间依赖（一个任务的输出是另一个的输入）

ObjectRef 可以直接传给另一个远程函数，Ray 会自动处理依赖：

```python
@ray.remote
def step1(x):
    return x * 2

@ray.remote
def step2(x):
    return x + 10

@ray.remote
def step3(x):
    return x ** 2

# 串行管道：step1 → step2 → step3
# 注意：这里直接传 ObjectRef，不需要 ray.get
r1 = step1.remote(5)        # 5 * 2 = 10
r2 = step2.remote(r1)       # 10 + 10 = 20（Ray 自动等 r1 完成）
r3 = step3.remote(r2)       # 20 ** 2 = 400（Ray 自动等 r2 完成）

result = ray.get(r3)
print(result)  # 400
```

**关键：** 把 ObjectRef 当参数传给 `.remote()` 时，Ray 自动识别依赖关系，等前一步完成再执行。

### 练习 2.1：串行 vs 并行

文件：`exercise_2_1.py`

```python
"""
练习 2.1：对比串行和并行的执行时间
目标：直观感受 Ray 并行的加速效果
"""
import ray
import time

ray.init(address='auto')


def slow_add_serial(a, b):
    """普通函数"""
    time.sleep(1)
    return a + b


@ray.remote
def slow_add_parallel(a, b):
    """远程函数"""
    time.sleep(1)
    return a + b


# ===== 串行：一个一个跑 =====
print("===== 串行执行 =====")
start = time.time()
results = []
for i in range(10):
    results.append(slow_add_serial(i, i + 1))
print(f"  10 个任务串行耗时: {time.time()-start:.1f}s")
print(f"  结果: {results}")


# ===== 并行：同时跑 =====
print("\n===== 并行执行 =====")
start = time.time()
futures = [slow_add_parallel.remote(i, i + 1) for i in range(10)]
results = ray.get(futures)
print(f"  10 个任务并行耗时: {time.time()-start:.1f}s")
print(f"  结果: {results}")

print(f"\n集群资源: {ray.cluster_resources()}")
ray.shutdown()
```

**预期：** 串行约 10s，并行约 1s（10 个任务同时执行）。

### 练习 2.2：ray.wait 流式处理

文件：`exercise_2_2.py`

```python
"""
练习 2.2：用 ray.wait 实现流式处理
目标：理解 ray.wait 的用法，谁先完成先处理谁
"""
import ray
import time
import random

ray.init(address='auto')


@ray.remote
def random_task(task_id):
    """随机耗时的任务"""
    duration = random.uniform(0.5, 3.0)
    time.sleep(duration)
    return task_id, round(duration, 2)


# 提交 10 个随机耗时的任务
futures = [random_task.remote(i) for i in range(10)]

print("开始流式处理（按完成顺序输出）：")
print("-" * 40)

remaining = futures
order = 1
while remaining:
    done, remaining = ray.wait(remaining, num_returns=1)
    task_id, duration = ray.get(done[0])
    print(f"  第 {order} 个完成: Task-{task_id} (耗时 {duration}s)")
    order += 1

print("-" * 40)
print("全部完成！")

ray.shutdown()
```

**预期：** 任务按完成时间排序输出，而不是按提交顺序。

"""
练习 2.3：num_cpus 资源控制
目标：理解资源分配如何影响并行度
"""
import ray
import time
import socket

ray.init(address='auto')


@ray.remote(num_cpus=5)
def resource_task(i):
    """每个任务占 5 个 CPU"""

print(f"集群资源: {ray.cluster_resources()}")

start = time.time()

results = ray.get(futures)
elapsed = time.time() - start

for r in results:

### 练习 2.4：任务管道

文件：`exercise_2_4.py`

```python
"""
练习 2.4：ObjectRef 自动依赖
目标：理解任务间传 ObjectRef 时自动等待的机制
"""
import ray
import time

ray.init(address='auto')


@ray.remote
def download(url):
    """模拟下载"""
    time.sleep(2)
    return f"[{url}的数据]"


@ray.remote
def parse(data):
    """模拟解析"""
    time.sleep(1)
    return f"解析完成: {data[:20]}..."


@ray.remote
def save(result):
    """模拟保存"""
    time.sleep(0.5)
    return "保存成功"


urls = [
    "http://api/data1",
    "http://api/data2",
    "http://api/data3",
]

# 为每个 URL 构建管道：download → parse → save
print("构建 3 条管道（download → parse → save）：\n")

start = time.time()
save_futures = []
for url in urls:
    d = download.remote(url)    # 步骤 1
    p = parse.remote(d)         # 步骤 2（自动等 d 完成）
    s = save.remote(p)          # 步骤 3（自动等 p 完成）
    save_futures.append(s)

results = ray.get(save_futures)
elapsed = time.time() - start

print(f"3 条管道并行，总耗时: {elapsed:.1f}s")
print(f"（串行需要 3 × 3.5 = 10.5s）\n")

for r in results:
    print(f"  {r}")

ray.shutdown()
```

**预期：** 约 3.5s（下载 2s + 解析 1s + 保存 0.5s，3 条管道并行）。
