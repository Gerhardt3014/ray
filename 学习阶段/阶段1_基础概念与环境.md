## 1. Ray 是什么

Ray 是一个**分布式计算框架**，用一行装饰器 `@ray.remote` 就能把普通 Python 函数变成分布式任务，自动调度到集群中的多台机器上并行执行。

### 为什么需要 Ray

假设你要处理 1000 个文件：

```python
# 普通写法：串行，很慢
results = []
for file in files:
    results.append(process(file))  # 一个一个处理

# 多线程/多进程：只能用一台机器的资源
from multiprocessing import Pool
with Pool(8) as p:
    results = p.map(process, files)  # 最多用 8 核

# Ray 写法：自动分布到多台机器，用尽集群所有 CPU
@ray.remote
def process(file):
    ...

futures = [process.remote(f) for f in files]  # 1000 个任务自动调度
results = ray.get(futures)
```

**核心区别：** 多线程/多进程只能用一台机器，Ray 能把任务分发到多台机器。

## 2. 核心架构

```
                    ┌─────────────────────────────────┐
                    │         Head 节点                │
                    │    192.168.31.115                │
                    │                                 │
                    │  ┌─────┐  ┌───────┐  ┌───────┐  │
                    │  │ GCS │  │Raylet │  │Dashbd │  │
                    │  │:6379│  │       │  │ :8265 │  │
                    │  └──┬──┘  └───┬───┘  └───────┘  │
                    └─────┼─────────┼────────────────┘
                          │         │
              ┌───────────┼─────────┼───────────┐
              │           │         │           │
              ▼           ▼         ▼           ▼
        ┌──────────┐  ┌──────────────────────────┐
        │ Worker   │  │ Worker                   │
        │ (Head上  │  │ 192.168.31.51            │
        │  的本地  │  │                          │
        │  Worker) │  │  ┌───────┐  ┌────────┐  │
        └──────────┘  │  │Raylet │  │Workers │  │
                      │  └───────┘  └────────┘  │
                      └──────────────────────────┘
```

### 各组件的作用

| 组件 | 作用 | 类比 |
|------|------|------|
| **GCS** (Global Control Service) | 全局调度中心，管理集群状态 | 公司的总经理 |
| **Raylet** | 每个节点上的本地调度器 | 车间的班长 |
| **Worker** | 实际执行 Python 代码的进程 | 车间的工人 |
| **Dashboard** | Web 管理界面，查看集群状态 | 公司的监控大屏 |
| **Plasma Store** | 分布式共享内存，存储任务间的数据 | 公司的共享仓库 |

### 数据流

```
1. 你写 @ray.remote def task(x): ...
2. 调用 task.remote(42) → 任务提交给 GCS
3. GCS 找一个有空闲 CPU 的节点，把任务分配给该节点的 Raylet
4. Raylet 启动一个 Worker 进程来执行任务
5. 返回值存入 Plasma Store（共享内存）
6. ray.get(future) 从 Plasma Store 取回结果
```

## 3. 实操：集群启停

### 3.1 裸机方式

```bash
# ===== Head 节点（本机 192.168.31.115）=====
conda activate ray_env

# 启动
ray start --head --port=6379 --dashboard-host=0.0.0.0

# 查看状态
ray status

# 停止
ray stop

# ===== Worker 节点（192.168.31.51）=====
ssh hgh@192.168.31.51
conda activate ray_env

# 加入集群
ray start --address='192.168.31.115:6379'

# 停止
ray stop
```

### 3.2 Docker 方式

```bash
# ===== Head 节点 =====
# 启动
docker run -d --name ray-head --network host --shm-size=4g \
  -v /tmp/ray:/tmp/ray \
  rayproject/ray:2.55.1 \
  bash -c "ray start --head --port=6379 --dashboard-host=0.0.0.0 --block"

# 查看日志
docker logs ray-head

# 停止并删除
docker stop ray-head && docker rm ray-head

# ===== Worker 节点 =====
# 启动（在 Worker 机器上执行）
docker run -d --name ray-worker --network host --shm-size=4g \
  -v /tmp/ray:/tmp/ray \
  rayproject/ray:2.55.1 \
  bash -c "ray start --address=192.168.31.115:6379 --block"

# 查看日志
docker logs ray-worker

# 停止并删除
docker stop ray-worker && docker rm ray-worker
```

### 3.3 `--shm-size=4g` 是什么意思

Ray 用共享内存（`/dev/shm`）存储任务间传递的数据。Docker 默认只给 64MB，远远不够。
`--shm-size=4g` 分配 4G 共享内存，这是 Ray 官方推荐的最小值。

### 3.4 `--network host` 是什么意思

让容器直接使用宿主机的网络，不做端口映射。这样：
- Head 容器直接监听宿主机的 6379 和 8265 端口
- Worker 容器可以直接连接 Head 的 IP
- 避免复杂的端口映射配置

### 练习 2：第一个 Ray 程序

将以下代码保存为 `学习阶段/exercise_1_1.py` 并运行：

```python
"""
练习 1.1：第一个 Ray 程序
目标：理解 @ray.remote、.remote()、ray.get() 的基本用法
"""
import ray
import socket
import os

# 连接到已有集群
ray.init(address='auto')

# ============================================================
# 第一步：定义远程函数
# @ray.remote 把普通函数变成"远程任务"
# 调用时不直接执行，而是提交到集群上执行
# ============================================================

@ray.remote
def say_hello(name):
    """这个函数会在集群的某个 Worker 上执行"""
    hostname = socket.gethostname()
    pid = os.getpid()
    return f"Hello {name}! I'm {hostname} (PID: {pid})"


# ============================================================
# 第二步：提交任务
# .remote() 提交任务，立即返回一个 ObjectRef（类似"取餐小票"）
# 此时任务可能还没执行完
# ============================================================

print("提交 10 个任务...")
futures = []
for i in range(10):
    future = say_hello.remote(f"Task-{i}")  # 立即返回，不等待
    futures.append(future)
    print(f"  提交 Task-{i}，得到 ObjectRef: {future}")


# ============================================================
# 第三步：获取结果
# ray.get() 拿着"取餐小票"去取结果，会阻塞等待任务完成
# ============================================================

print("\n获取结果...")
results = ray.get(futures)  # 等待所有任务完成
for r in results:
    print(f"  {r}")

# 打印集群信息
print(f"\n集群资源: {ray.cluster_resources()}")

ray.shutdown()
```
